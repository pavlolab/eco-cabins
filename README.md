EcoCabins is a responsive landing page for an eco-friendly cabin rental service. The project showcases modern UI design, clean layout structure, and adaptive behavior across different screen sizes.

The website includes multiple sections such as a hero block with background image, information about materials, innovation highlights, and a structured footer. It also features a slider component for visual presentation.

🔗 Live Demo: https://pavlolab.github.io/eco-cabins/

Technologies used:
- HTML5
- CSS3 (Flexbox, Grid), Swiper
- SCSS
- JavaScript (basic interactivity)

The project focuses on building a clean and visually appealing layout with attention to typography, spacing, and responsive design.
